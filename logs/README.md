# Development Logs

This folder records meaningful changes to the project.

## Naming

Use:

`YYYY-MM-DD-short-description.md`

Example:

`2026-08-20-source-ingestion.md`

## Each log should include

- Date
- Objective
- Files changed
- What was implemented
- What was intentionally not implemented
- Bugs/issues
- Decisions made
- Next step

## AI handoff rule

When another AI continues this project, read:

- `PROJECT.md`
- `CHANGELOG.md`
- this README
- the latest development log

Do not assume a feature exists because it appears in the product vision. Check the code and changelog.
